# BioLik Luxe React + Firebase

## Installation
npm install
npm run dev

## Firebase
1. Firestore collections: products, orders, promoCodes, settings.
2. Authentication: enable Email/Password and create admin user.
3. Rules: copy firestore.rules into Firebase Firestore Rules.

## Product fields
name_fr, name_en, name_ar, description_fr, description_en, description_ar, category, skin, origin, price, oldPrice, stock, images (array or admin textarea).

## Shipping
Morocco free, Europe $15, USA/Canada $34, Gulf $24.
